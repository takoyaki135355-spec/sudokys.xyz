# 🛡️ sudokys.xyz

> Personal portfolio, security research hub, web tools, & CTF playground for **Tako**.

---

## 🚀 Features

- 🖥️ **Interactive Terminal Shell**: Terminal window supporting live commands (`whoami`, `skills`, `projects`, `contact`, `matrix`, `flag`, `clear`).
- 🟢 **Matrix Digital Rain**: High-performance HTML5 Canvas matrix background effect with audio SFX toggle.
- ⚡ **REFRACT**: Interactive canvas laser optics & reflection physics puzzle game with custom Web Audio synth.
- 📝 **.Txt Editor**: Distraction-free browser notepad featuring auto-save, live word/character stats, theme toggles, and `.txt` file export.
- 🔒 **Contact & PGP Gateway**: One-click copy buttons for contact channels and PGP key verification (`5666A15E`).
- 🚩 **CTF Challenges**: Scattered flags, header comments, and secret endpoints for security enthusiasts.

---

## 🛠️ Built With

- **HTML5 & Vanilla CSS3**: Sleek dark mode, glassmorphism, responsive grid layout.
- **Vanilla JavaScript**: ES6+, HTML5 Canvas API, and Web Audio API (no external framework overhead).
